# Cielo-Eventi — public site

The built pages of **Cielo-Eventi**, a pre-registered study that tests, with rules fixed in advance, whether the
positions of the planets say anything about events on Earth. It is built so that it can fail.

- The site: https://sisco128.github.io/cielo-eventi-site/
- How to take part (questions, critiques, proposals, replication offers): https://sisco128.github.io/cielo-eventi-site/contribute/

The study's repository is private; this repository holds the published pages (branch `gh-pages`) and the issues.
Open an issue with one of the templates. Every Friday the council reads what arrived and answers in plain words,
linking the minute where the item was discussed. No external input can change a frozen primary analysis of this
study; it can change how we work, what we explain, and what the next study asks.
