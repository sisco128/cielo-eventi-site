    Protocol v0.4 — English translation of the text fields¶

    Translation. protocol-v0.4.json is frozen (SHA-256 in FREEZE.md) and its text fields are in Italian. This file translates every text field longer than a few words, by JSON path. Keys, numbers and short codes are already language-neutral and are not repeated. If this translation and the JSON disagree, the JSON wins. Amendment #28 replaced the markets source after the freeze: see docs/protocol/AMENDMENTS.en.md.
